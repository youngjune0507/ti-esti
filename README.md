# 철학 독서 노트 (제텔카스텐)

## 폴더 구조

| 폴더 | 용도 |
|------|------|
| `문헌/` | 책·강의 단위 노트. 파일명: `저자-제목.md` |
| `개념/` | 아이디어 하나당 파일 하나. 파일명: `개념명.md` |

## 파일명 규칙

- 한글 사용, 공백 대신 하이픈
- 예: `홍창성-서양철학강의.md`, `지식과-지혜.md`

## Foam 링크 사용법

- 노트 간 연결: `[[파일명]]` (확장자 없이)
- Foam Graph에서 연결 관계 시각화 가능

## 에디터 설정

- VS Code + Foam 확장 사용
- `Ctrl+Shift+P` → `Foam: Show Graph` 로 그래프 확인
